# 设备工具箱

### ⬇️ [点此一键安装](https://www.scripting.fun/import_scripts/?urls=%5B%22https%3A%2F%2Fraw.githubusercontent.com%2Fios151%2FScripting%2Fmain%2Fdist%2FDeviceToolbox.zip%22%5D)

**在 iPhone / iPad 上用 Safari 打开这个链接**，会直接唤起 Scripting 导入。
在电脑上点是没用的——那台机器上没有 Scripting。

走苹果官方的开发者通道管本机：设备信息、电池健康、主屏布局、应用管理、签名诊断、
实时性能。和 WLOC 虚拟定位同一套协议层，只是下游换成了别的服务。

```
本机配对（RemotePairing）→ 回环隧道 → TLS-PSK 加密隧道 → RSD 查服务 → 各服务收发 plist
```

> ⚠️ **0.22 之前的功能都在真机上跑过；之后新加的几项（系统事件、内存显示、长按菜单自定义）还没完整验证。**
> 自己写自己用的东西，遇到问题开 issue。

## 能做什么

**设备信息**

型号、系统版本、存储、ECID、序列号这些，来自 lockdown 和 RSD 握手时的 Properties。
点一行或长按都能复制。

**电池健康**

循环次数、设计容量与满充容量、健康度、充放电功率。满充容量优先取
`NominalChargeCapacity`，两个字段都有时都列出来；大号数字和系统一样封顶 100%，
超出的部分另起一行说明。开实时刷新后每 2 秒记一个点，画成充电曲线，
还能把电量推到锁屏卡片和灵动岛。

**真机拿不到电池温度**：IOPMPowerSource、AppleSmartBattery、GasGauge 三路都没有，
所以界面写「设备未提供」，不编一个数出来。

**主屏布局**

读 Dock 和主屏各页，导出成图或 plist，可以调 Dock 里的顺序、把图标移回某一页，
还能交给 AI 整理（按用途分组、按名称或颜色排序、按颜色建文件夹）。
每次写回前自动备份，保留最近 20 份。

**负一屏（今天视图）备份不了**：`getIconState` 返回的只有 Dock 和主屏各页，
负一屏的小组件由系统单独管，不在这份数据里。

**应用管理**

自己装的 App，列版本、占用空间、安装来源（按签名推断）、安装 / 更新时间，
可搜索、可按来源筛选、可复制清单。图标边取边铺，大小算完存缓存。
支持左滑卸载、长按菜单（菜单里放哪几项、什么顺序自己定）、多选批量卸载，
以及「查 App Store 链接 → 分享出去 → 再问要不要卸载」这条换机用的流程。

**使用频次和最后使用时间拿不到**：屏幕使用时间不走开发者通道；
installation_proxy 返回的整份字典里也没有任何最后使用时间字段。

**签名到期 / 签名检查**

描述文件还剩几天、谁在用；自签的包装不上或打不开时，逐条诊断证书、App ID、
匹配的描述文件、有效期、本机 UDID 在不在设备列表里、entitlements 有没有超范围。
**证书比描述文件先到期时会额外提醒**——免费号证书 7 天、描述文件一年，
只看描述文件会算多。带一个模拟时间开关，用来测各种到期显示，只在内存里，重开就恢复。

**实时性能**

走 Instruments 那条通道（DVT），全机 CPU、内存、吃 CPU 最多的进程。
只看，不做结束进程之类的操作。要先挂上开发者磁盘镜像，没挂会直接说清楚。

**系统事件**

订阅 notification_proxy，装 App、锁屏、改设置这些系统内部事件会当场跳出来。
**只订阅只接收，不往系统里发任何东西。**

**底层查询**

MobileGestalt 属性查询，预设分五组，也能手输键名。标识类默认打码。
另有开发者磁盘镜像和开发者模式的状态。

**电源**

重启、关机、睡眠，走 diagnostics_relay。

## 要求

- **TestFlight 版的 Scripting**。App Store 版没有 `VPN.localDevVPN`，整条链路第一步
  就走不通，和 WLOC 一样
- **iOS 27+**。协议层本身的下限是 iOS 17（RemotePairing / RSD 是 17 才有的），
  但实际卡点在配对：**iOS 27 以下拿不到 PIN**，配不上对后面就无从谈起。
  这是 WLOC 那边实测出来的，两个脚本用的是同一份 `core/pair_setup.ts`
- **开发者模式必须开**：设置 → 隐私与安全性 → 开发者模式
- 实时性能那一页还需要**开发者磁盘镜像已挂载**

## 已知限制

这些不是 bug，别重复排查。

- **同时只能有一条设备隧道** —— WLOC 在模拟定位时这里连不上，反之亦然。
  配对记录也**不互通**：Scripting 的 Keychain 按脚本隔离，这个脚本读不到 WLOC 存的那份。
  可以在 WLOC 的「配对」页导出一份，再到这里导入，就不用重新输 PIN。
- **蜂窝数据下要开关一次飞行模式** —— 和 WLOC 同一个原因：配对服务靠 mDNS 公告，
  而蜂窝接口上没有本地链路。脚本会检测当前链路并提前提醒。连上之后蜂窝照常用。
- **拿不到的东西就说拿不到** —— 电池温度、App 的使用频次和最后使用时间、
  负一屏布局、「系统数据」那类分项存储，都查实过确实没有，界面上直接写明，不编数字。
- **锁屏、熄屏、切网络会把隧道收掉** —— 实时性能和系统事件这两页挂着长连接，
  断了会提示「连接断开了」，点右上角重新开始即可。这两页跑的时候会申请后台保活。
- **卸载不可撤销** —— 卸载会连 App 在本机的数据一起删，每次都会弹窗确认。
  Scripting 自己永远不在可卸载之列。
- **诊断报告不含 UDID 和序列号** —— 调试日志也只记长度不记内容，密钥材料一律不进日志。
