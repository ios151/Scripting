# 快捷指令签名

### ⬇️ [点此一键安装](https://www.scripting.fun/import_scripts/?urls=%5B%22https%3A%2F%2Fraw.githubusercontent.com%2Fios151%2FScripting%2Fmain%2Fdist%2FShortcutSigner.zip%22%5D)

**在 iPhone / iPad 上用 Safari 打开这个链接**，会直接唤起 Scripting 导入。
在电脑上点是没用的——那台机器上没有 Scripting。

在**手机本机**给快捷指令签名：不要服务器、不要 Mac、不靠第三方签名服务。

iOS 15 起，未签名的快捷指令导不进去，只能导入签过名的 `.shortcut`（文件头 `AEA1`）。Apple 官方只有 macOS 的
`shortcuts sign` 能签，别的路子都要靠第三方服务。这个脚本换了条路：**自己生成一张根证书，装到手机上并信任它，
再用它签。** 系统校验这种签名时，除了证书链能验到受信任的根，只看链首证书带不带 `1.2.840.113635.100.18.1` 这个扩展
——两样都满足就放行。

```
生成根证书和叶证书 → 你在「设置」里装上并信任根证书 → 用叶证书的私钥签 .shortcut → 分享面板里导入快捷指令
```

> ⚠️ **新脚本，真机验证还不完整。** 2026-10-28 在 iPhone（iOS 27.2）上验证过：脚本能起、证书页正常、身份生成成功，
> 装好并信任证书之后，用同样做法签出来的快捷指令能导入并运行。**还没在真机上验证的**：Safari 装描述文件那条路（修过一处 bug，
> 没重试）、存到「文件」那条路、改名后「证书信任设置」里显示的名字、连签多个快捷指令会不会互相替换、原生压缩、
> 分享面板入口、无界面 API、证书页第四步（实验）。详见下面的「真机验证状态」。自己写自己用的东西，遇到问题开 issue。

---

## 要求

- Scripting：按 3.3.0（TestFlight 版）的类型定义开发，App Store 版（3.2.x）没试过
- iOS：只在 iOS 27.2 上验证过。这套签名格式是 iOS 15 起用的，更低的系统不适用
- 手机上要装并信任一张自己生成的根证书（第一次用时做一次，见下面）

## 怎么用

1. **证书页 → 第一步**，装证书，两条路任选其一：
   - 「下载并安装证书（Safari）」：打开 Safari，系统问「是否允许下载配置描述文件」选**允许**；
   - 「存到『文件』，在文件里点开装」：证书存成 `.cer` 放进 `文件 → 我的 iPhone → Scripting → 快捷指令签名证书/`，
     脚本会尝试直接跳到那个文件夹，你点那张证书，系统同样会当描述文件接手。
2. **证书页 → 第二步**（脚本代劳不了，系统不让）：
   - 「设置」最上面「已下载描述文件」→ 安装；
   - 「设置 → 通用 → 关于本机 → 证书信任设置」→ 打开这张证书的开关（名字就是证书页里显示的那个）。

   做完在第二步底下打个勾「我已经装好并信任了这张证书」：脚本检测不到系统里的信任状态，只能靠你点；
   打了勾，首页的「先装证书」提示就不再出现（重新生成证书会自动取消这个勾）。
3. **证书页 → 第三步**：点「试签一个测试快捷指令」→ 分享面板里选「快捷指令」→ 导入 → 运行，弹出提示框就说明整条链都通了。
4. 之后回首页，用「选择文件…」「粘贴剪贴板里的 plist」「输入链接…」（粘贴 .shortcut 后缀的 https 链接）给任意快捷指令签名
   （文件可以一次选多个），结果行里点「导入」。已经签过名的文件也能换成这里的签名。
5. 不想先打开脚本也行：在别的 App 里（「文件」、Safari 下载、聊天软件……）长按 `.shortcut` 文件 → 分享 → Scripting →
   「快捷指令签名」，文件会直接进来、自动签，结果行里点「导入」。一次分享多个也行。
   这条路只收**文件**；文字、链接、图片不收（免得系统里随便分享点什么，都弹出这个脚本）。
6. （可选，**实验**）**证书页 → 第四步**：「导入『证书设置跳转』快捷指令」→ 分享面板里选「快捷指令」导入；以后点「运行它，跳到设置」，
   在弹出的菜单里选「描述文件」或「证书信任设置」，由快捷指令的「打开 URL」去开 `prefs:` 链接。脚本自己打不开这些链接
   （iOS 27.2 上实测被系统拒绝，只放行快捷指令这类系统应用），所以借一个快捷指令；它自己要等证书信任了才导得进去，
   第一次装证书用不上，重装 / 换证书 / 删旧描述文件时才用得着。**这两条链接在 iOS 27 的快捷指令里通不通没验证过**：
   没反应或报错，是系统不放行；落在「设置」首页，是认了 App 但不认具体的页；都照第二步的文字走。

证书只装一次。每台要导入的设备各装各的：签出来的文件**只有信任这张根证书的设备才导得进去**。想公开分享，
就先导入到自己的快捷指令里，再用快捷指令自己的「拷贝 iCloud 链接」，那样上传的是 Apple 重新签过的版本。

**证书名称可以改**：证书页「证书名称」。名字是签进证书里的（「证书信任设置」里列的就是它），所以改名等于用新名字
重新生成一整套，手机上要重装、重新信任。没生成过证书时改名只是先记下，第一次生成就用它；不改就是
「Shortcut Signer Root」加 4 位随机后缀，改了就原样用你起的名字（1 到 40 个字）。

## 它做了什么

```
plist（XML / 二进制 / 已签名）→ 校验是快捷指令 → 统一成二进制 plist
  → AA01 归档（目录 + Shortcut.wflow）→ AEA1 容器（证书链放授权数据里，叶私钥做 ECDSA 签名）
  → 自检（Apple 校验的那一套：HMAC 链、签名、段校验和、总长，验不过就丢掉不交）
  → 临时目录里的 .shortcut → 分享面板 / 打开方式 / 存到「文件」
```

- **根私钥生成完叶证书就丢掉了**，从不存盘。手机里装的是根证书，信任它是整机生效的；
  根私钥要是还在，就能给这台手机签任意网站的证书。留下的只有只能签快捷指令的叶私钥，存在钥匙串里（按脚本隔离，
  不同步 iCloud、不迁到新手机）。代价：叶证书不能换，想换只能整套重新生成、手机上重装重信任。
- 压缩用 Scripting 原生的 LZFSE（`Data.compressed`），压出来的东西形状不对、或自检过不了，就退回不压缩——格式允许，
  只是文件大一点。结果行里会写「LZFSE」还是「未压缩」。
- 密码学部分（SHA-256 / HMAC / HKDF、P-256 与 ECDSA、DER / X.509、plist、AEA1）全是自己写的纯 TypeScript，
  不依赖任何上游源码；写入端拿 24 个 Apple 官方签名的真实快捷指令逐字节对拍过（样本多为他人作品，不随仓库分发）。

## 无界面 API（给别的脚本调用）

别的脚本可以用 `Script.run({ name: "快捷指令签名", queryParameters: { action, … } })` 调用，不弹界面。
`action` 有三个：

| action | 参数 | 返回 |
|---|---|---|
| `status` | 无 | 证书状态：有没有身份、你有没有确认装好信任、名称、指纹、有效期，以及下一步该做什么 |
| `check` | `paths`（要检查的文件的绝对路径，最多 20 个；单个文件可用 `path`）、`strict`（可选，警告也当错误） | 每份一条结果：通过与否、动作数和动作标识、错误和警告（稳定的 `code` + 位置 `path` + 中文说明，各最多 50 条）。只读，不需要证书，不写任何文件 |
| `sign` | `paths`（要签的文件的绝对路径，最多 20 个；单个文件可用 `path`）、`outputDir`（签好的放哪，可选） | 每份一条结果：成功的有路径、大小、动作数、动作标识，失败的有原因；另附证书状态 |

约定：只收文件路径、不收 plist 正文；永远不抛，失败是 `{ ok: false, error: { type, message } }`；证书没确认装好时结果里会明说，
不会说成「能导入」。参数里没有字符串 `action` 就是平常打开，弹界面。接口版本 `apiVersion` 现在是 2。`sign` 不会自动先 `check`。

`check` 是**结构检查**，不是行为保证：查 plist 外层、动作的标识和参数、动作 UUID 的形状和唯一性、变量引用能不能对上某个动作的 UUID、
`attachmentsByRange` 的键和占位符、控制流分组、App Intent 描述是否自洽、系统动作的标识是不是登记过的常见动作
（不在只给警告 `unknown_action`，多半是拼错了）；**通过只说明「结构上没发现问题」**，导入后能不能运行要真机试。
没有名字不算错（真实快捷指令的 `Shortcut.wflow` 里本来就没有 `WFWorkflowName`，名字在文件名里），只给警告 `missing_name`；
24 个 Apple 签名的真实快捷指令跑下来没有任何错误。

## 排查

| 现象 | 多半是 |
|---|---|
| 导入时提示「无法验证」「未信任」「已损坏」 | 证书没装，或装了没在「证书信任设置」里打开开关。回证书页重做第二步 |
| 点「下载并安装证书」之后 Safari 没弹提示 | 看 Safari 有没有被拦截；脚本等 60 秒没人取会提示「没等到 Safari 取走描述文件」，再点一次；或改用「存到『文件』」那条路 |
| Safari 一直转圈 | 后台保活没开成（脚本会提示）：音频被别的 App 占着（在放音乐）时系统不给保活，暂停音乐再点一次 |
| 提示「已交给 Safari」，设置里却没有「已下载描述文件」 | Safari 弹窗没点「允许」（脚本只知道 Safari 来取过，不知道你点了什么），回来再点一次 |
| 默认浏览器不是 Safari | 别的浏览器装不了描述文件，永远看不到「已下载描述文件」。装证书前把默认浏览器改回 Safari，或者走「文件」那条路 |
| 选文件时某个文件报「读不了」 | iCloud 里还没下载的文件，先在「文件」里点一下下载；别的文件不受影响，照常签 |
| 报「认不出这个文件」 | 选的不是快捷指令。报错里写了**共多少字节、开头是哪几个字节**，拿它核对：`3C 3F 78 6D 6C`（`<?xml`）是 XML plist，`62 70 6C 69 73 74 30 30`（`bplist00`）是二进制 plist，`41 45 41 31`（`AEA1`）是已签名的快捷指令，这三种才认；`50 4B`（`PK`）是 zip 压缩包，先解压。大小和「文件」里看到的对不上，就是选错了文件 |
| 报「这是网页（HTML）」 | 链接拿回来的是网页而不是文件：多半不是文件直链（GitHub 的文件页要换成 raw 链接），或者要先登录才能下载 |
| 剪贴板报「没有文字」 | 系统弹「允许粘贴」时要选允许；也可能在「设置 → Scripting → 从其他 App 粘贴」里被拒绝了 |
| 提示「签名身份读不出来」 | 钥匙串里的身份文件损坏。证书页最下面「重新生成签名身份」恢复（脚本不会悄悄重新生成，那会让手机上已经信任的证书作废） |
| 「文件」里点了证书没反应 | 确认点的是 `.cer` 那个文件；还不行就用 Safari 那条路 |
| 分享面板里没有「快捷指令」 | 改用结果行的「打开方式」；还不行就「存到文件」，在「文件」里点开 |
| 在别的 App 的分享面板里找不到「快捷指令签名」 | 先确认分享的是**文件**（文字 / 链接不收）；分享面板里要先点 Scripting，再选这个脚本；脚本的 Intent 设置里要勾上「文件」（在 Scripting 里点脚本标题进「Intent 设置」）；都对还不行，就用首页的「选择文件…」 |
| 结果行写「未压缩」 | 原生 LZFSE 不可用、或压出来的结果没过形状 / 自检。不影响导入，文件大一点而已 |
| 重新生成 / 改名之后旧文件还能导吗 | 手机还信任旧根证书就能；删了旧证书就不能。旧证书在「设置 → 通用 → VPN 与设备管理」里删 |
| 换手机 / 删了脚本 | 钥匙串里的身份随脚本一起回收，要重新生成、重新装证书 |

## 已知局限

- 脚本**检测不到**证书是否已被信任（没有对应的 API），所以证书页只能写步骤，不能自动判断做到哪一步。
- 「设置」里的深链（证书信任设置、已下载描述文件）**脚本自己**一条都跳不过去：`prefs:` 被 Scripting 拦，`App-prefs:` 在 iOS 18 起只认
  bundle ID（iOS 27.2 上实测过）。所以第二步仍以文字步骤为准；第四步借快捷指令去开只是实验，
  它还有个先后问题：导入它要用这张证书签，证书得先装好并信任，**第一次装证书帮不上忙**。
- 叶证书是固定的一张；Apple 自己签的文件每份都是一张新叶证书（CN 各不相同）。系统会不会把「叶证书 CN 相同」的
  快捷指令当成同一个，**没验证过**。
- 单个文件上限 256 MiB（AEA 单簇 256 段 × 1 MiB），远大于任何实际的快捷指令。
- 分享入口只收文件。分享文字 / 链接、或在快捷指令 App 里用「运行脚本」传文字 / JSON（而不是文件），都不处理。

## 真机验证状态

**已验证（2026-10-28，iPhone，iOS 27.2）**

- 脚本能起、证书页界面正常渲染；第一次点按钮时身份生成成功，名称 / 有效期 / SHA-256 指纹都显示出来了
  ——BigInt 椭圆曲线在设备上能跑，速度不是问题。
- 同样做法（自建根证书）签出来的同样形状的文件，在这台手机上导入并运行成功。
- 证书页勾了「我已经装好并信任了这张证书」，首页的「先装证书」提示随之消失、证书行显示「已装好」。
- 「输入链接…」「选择文件…」两个入口跑过，各暴露一个问题（点取消报 `text.trim`、选未签名的 plist 一律「认不出」），**都已修，修后还没复测**。

**还没验证**

1. 证书页「下载并安装证书（Safari）」：Safari 弹「允许下载描述文件」、设置里出现「已下载描述文件」
   （本机 HttpServer + `Safari.openURL` + 后台保活；第一次试时栽在 `HttpServer.start()` 成功返回 `undefined` 上，已修，待重试）。
2. 证书页「存到『文件』」：能不能直接跳进「文件」里的 `快捷指令签名证书` 文件夹（`shareddocuments://` 深链），点 `.cer` 之后系统是不是接手。
3. 「证书信任设置」里出现这张证书、打开开关；改名后显示的是新名字。
4. 连签两三个**不同**的快捷指令、都导入：看它们是各自独立存在，还是后一个替换了前一个（叶证书 CN 固定的风险）。
5. 结果行写的是「LZFSE」还是「未压缩」；「LZFSE」那种文件导入是否正常；把已签名的 `.shortcut` 再丢进来「换签名」（要原生解压）。
6. 分享入口：在「文件」里长按一个 `.shortcut` → 分享 → 列表里有没有 Scripting → 选「快捷指令签名」→ 是不是弹出完整界面、文件自动签好。
7. 无界面 API：别的脚本用 `Script.run` 调 `status` / `check` / `sign`，结果能不能原样回来。
8. 证书页第四步（实验）：导入「证书设置跳转」→ 运行 → 菜单里两项各落在哪（没反应 / 设置首页 / 对的页）；
   `shortcuts://run-shortcut?name=…` 能不能从 Scripting 里打开；导入后的名字是不是「证书设置跳转」。

## 文件

```
index.tsx          启动入口；带 action 参数调用时不弹界面，走 kit/api.ts
intent.tsx         分享面板入口：别的 App 分享来的 .shortcut 文件，读成字节后交给首页自动签
pages/             App（首页：选来源、签、结果、入口）、
                   CertificatePage（装证书两条路 / 信任 / 试签 / 借快捷指令跳设置（实验）/ 改名 / 重新生成）
kit/               设备端胶水：钥匙串与 Storage、临时文件与分享、证书文件与「文件」App 深链、让「快捷指令」运行指定快捷指令、
                   取文件（含分享来的）/ 剪贴板 / 链接、本机 HttpServer + Safari 装描述文件、原生 LZFSE、
                   签名流程（签→自检）、无界面 API（api.ts：status / check / sign）
core/              纯 TS，设备和 Node 跑同一份：SHA-256 / HMAC / HKDF、P-256 与 ECDSA、DER / X.509、
                   签名身份、plist（读 XML / 二进制，写二进制 / XML）、AEA1 + AA01、认格式与读 plist、
                   结构检查、根证书描述文件、文件名清洗、内置测试快捷指令、第四步的跳转快捷指令
```
