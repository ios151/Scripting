# WLOC 虚拟定位

### ⬇️ [点此一键安装](https://www.scripting.fun/import_scripts/?urls=%5B%22https%3A%2F%2Fraw.githubusercontent.com%2Fios151%2FScripting%2Fmain%2Fdist%2FWLOC.zip%22%5D)

**在 iPhone / iPad 上用 Safari 打开这个链接**，会直接唤起 Scripting 导入。
在电脑上点是没用的——那台机器上没有 Scripting。

用苹果官方的开发者接口模拟本机定位，与 Xcode 的 Simulate Location 走同一套机制，
不涉及证书、代理改写或系统文件。

```
本机配对（RemotePairing）→ 回环隧道 → TLS-PSK 加密隧道 → RSD 查服务 → DVT 下发坐标
```

更新日志见 [Releases](https://github.com/ios151/Scripting/releases)。

---

## 能做什么

**选点**

地图上直接点，或点中餐厅、车站、景点这类地点直接命中（iOS 18+ 还会弹系统详情卡）。
标准 / 卫星 / 混合三种图层，3D 地形和路况随时开关，3D 倾斜视角下照样能点。
搜索支持国内和境外（境外走中转服务，原因见下面的已知限制），收藏和历史都在。

坐标卡片同时给出两套坐标：**GCJ-02**（地图上点出来的那个）和 **WGS-84**
（真正下发给设备、别的 GPS 工具认的那个），各带一个复制按钮。国内两者差几百米，
那个差值正是换算对了的证明；境外两系相同，只显示一行。

**移动**

- **沿路线**——选终点自动规划，多方案可选，支持往返多次
- **手绘路径**——地图上依次点出几个点，按这条线走
- **摇杆**——按住推，推得越远走得越快，松手即停；卡片能拖到屏幕任意位置
- **GPX 轨迹**——导入现成轨迹按所选速度重走

四种方式（步行 / 跑步 / 骑行 / 驾车）各三档速度，也可以自定义。

**状态**

锁屏卡片和灵动岛显示当前位置，锁屏上直接点「恢复真实位置」。
卡片标题、灵动岛的图标颜色文字都能改。

**排查**

「连接状态」逐项体检，定位卡在哪一环一目了然。运行日志常驻内存，一键导出成 txt
——**导出会自动脱敏**，坐标降到 1 位小数、地名和自定义文本打码、地址和设备标识只留前缀。

## 要求

- **TestFlight 版的 Scripting，3.3.0 (28) 或更高**。App Store 上架的是 3.2.1，
  **跑不了**（见下）
- **iOS 27+**
- **开发者模式必须开**：设置 → 隐私与安全性 → 开发者模式
- 灵动岛需要 iPhone 14 Pro 及以后的机型；没有的话实时活动仍会出现在锁屏和通知中心

当前装的是哪个 Scripting 版本，在脚本的「连接状态」页最下面能看到。

### 为什么 App Store 版不行

整条链路的第一步是本机回环隧道（`VPN.localDevVPN`），**那套接口只有 TestFlight
版才有**。没有它就建不起 TLS-PSK 隧道，后面的 RSD 查服务、DTX 下发坐标全部无从
谈起——这跟装哪个 WLOC 版本没有关系，装哪个都一样。

### 为什么 iOS 27 以下不行

就算装上了，**配对那一步拿不到 PIN**，配不上对后面也走不下去。
原因还没排查，目前不打算处理。

### 顺带：2.7.1 起对 3.3.0 的额外依赖

`ScriptSession`（锁屏按钮直通主脚本）、`BackgroundKeeper.getState`（保活失败的
原因）、`Device.getNetworkState`（诊断区分 WiFi / 蜂窝）、`Device.appVersion`
（诊断报宿主版本）、`cancelRSDTunnelOpening`（建隧道超时后取消残留的那次尝试）。

这条只用来区分 TF 的新旧版本。对 App Store 版没有意义——那边卡在回环，根本到不了
这些功能。

## 已知限制

这些不是 bug，别重复排查。

- **蜂窝数据下要开关一次飞行模式** —— 配对服务靠 mDNS 公告自己，而蜂窝接口上没有
  本地链路，发现不了它（两种隧道来源都一样）。连不上时脚本会弹引导：确认隧道已连接
  → 控制中心开关一次飞行模式 → 脚本自己重试到连上。**连上之后蜂窝照常用**，
  本地网络只在起步那一刻需要。用 WiFi 不需要这一步。
- **金融类应用改不了位置** —— 系统会给模拟位置打 `isSimulatedBySoftware` 标记，
  银行、保险等据此拒绝。这属于系统机制，本项目不绕过。
- **首次配对要去系统设置输 PIN** —— 脚本会把本机广播成可配对主机，但 PIN 只能在
  「设置 → 隐私与安全 → 开发者 → 配对」里输入，这一步系统不允许代劳。
  也可以继续用 wloc 导出的记录。
- **更新系统后需重新配对** —— 系统更新会让设备侧的配对授权失效。本地记录还在、
  握手也能过，但建隧道会失败，回「配对」页重配一次即可。
- **全球搜索依赖一个中转服务** —— 大陆 iPhone 的地图数据源是高德，没有境外 POI。
  实测系统接口不仅搜不到，还会拿国内同名建筑顶替（搜「Eiffel Tower」返回四川的
  山寨铁塔），所以境外搜索改走 Worker → OpenStreetMap。撞限额时可在设置里换成自建的。
- **同时只能有一条 VPN** —— 用 Scripting 自身的隧道会顶掉正在跑的代理工具。
  想两者并存，把「隧道来源」设为「代理工具提供」，并装上
  [dev-loopback 模块](../dev-loopback/)（Loon / Surge 现成可用，Egern 自己照文档写，
  Quantumult X 写法未验证）。
- **停止模拟后系统地图未必立刻回到真实位置** —— 拿 Xcode 做对照也一样，属于系统行为。
  打开地图 App 触发一次真实定位即可。
- **关掉脚本界面不会停掉定位** —— 模拟由设备侧维持，要停就点「恢复真实位置」，
  或者用锁屏卡片上的那个按钮。
